# Ashwin Kumar S — Portfolio

Personal portfolio site for **Ashwin Kumar S**, M.Sc. Data Science student at Loyola College, Chennai.

A single-page, scroll-linked site covering profile, education, skills, experience, projects, achievements and contact.

## Features

- Deep indigo theme with a layered background pattern (grid, dot matrix, waves, and animated data-science motifs)
- Animated 3D data cube with six colour-coded faces — Python, SQL, Power BI, ML, AI, Data
- Scroll-linked navigation with an active-section indicator and a reading-progress bar
- Reveal-on-scroll animations, animated counters and proficiency meters
- 3D tilt cards, magnetic buttons and pointer-driven parallax on desktop
- Fully responsive, with a full-screen hamburger menu below 1150px
- Respects `prefers-reduced-motion`

## Running it

No build step and no dependencies — it is plain HTML, CSS and JavaScript.

Open `index.html` directly in a browser, or serve the folder:

```bash
python -m http.server 5500
```

Then visit <http://localhost:5500>.
